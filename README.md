## ✨ Features

⏱️ **Clip cutter** — download only a chosen part of a video (set start & end time)

🎞️ **Video & audio** — MP4 up to 4K, or extract MP3 / WAV

📦 **ZIP picker** — look inside a ZIP and pick only the files you want

🖼️ **Background remover** — one-click transparent background for icons & logos

🧊 **3D preview** — rotate GLB / OBJ / STL / FBX models before saving

⚡ **Download manager** — resume, queue, speed limiter, scheduler

🛡️ **Safety warnings** — flags risky or disguised files before download

🌙 **Extras** — dark mode, per-site settings, download history

## ⬇️ Download and Install

Free, unofficial extension — it installs manually (not from the Chrome Web Store).

➡️ **Download the latest version:** https://github.com/arsalan0000000/blackhole-download-manager/releases/latest

**Step 1.** Download the ZIP and unzip it (keep the folder).

**Step 2.** Open the page `chrome://extensions`

**Step 3.** Turn on **Developer mode** (top-right).

**Step 4.** Click **Load unpacked** and select the unzipped folder.

**Step 5.** Pin the icon 📌 and enjoy.

It doesn't auto-update — to update, download the new version and reload.
